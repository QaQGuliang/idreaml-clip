02 / QUICK START

三步，让剪切板变得好用。

从一次普通复制开始。理梦剪藏会在后台记录，下一次复制不会覆盖掉你需要找回的内容。

STEP 01

启动应用

安装或解压后打开理梦剪藏。关闭主窗口后，它仍会留在系统托盘中继续运行。

STEP 02

复制一段内容

像平时一样复制文字、网址或图片。打开“全部历史”，即可看到刚才的记录。

STEP 03

按快捷键找回来

先点击目标输入框，再按 Ctrl + Shift + V，选中一条记录即可使用。

试试复制这句话：把常用内容，留在顺手的位置。

03 / CLIPBOARD

不用离开手头的工作。

快捷面板在鼠标附近打开。搜索、选取、使用，让常用内容少走几步。

从目标输入位置唤起，再选一条。

  1. 先点击需要输入内容的位置，按默认快捷键 Ctrl + Shift + V。
  2. 输入关键词筛选，或切到“收藏”查看常用内容；悬停图片和 JSON 可查看预览。
  3. 单击记录，或用 ↑ ↓ 选择后按 Enter 使用。按 Esc 收起面板。
常用内容，加一颗星

为常用回复、链接和代码片段添加收藏，之后更容易找到。

复制相同内容会合并

历史保留使用次数和最近使用时间，避免重复条目不断堆积。

部分输入框会限制自动粘贴。内容仍在剪切板时，可以手动按 Ctrl + V。
04 / CAPTURE & PIN

截下来，标清楚，贴在眼前。

普通截图、滚动长截图和贴图，覆盖不同的信息整理场景。

F1 截图与标注

按 F1 或点击快捷面板顶部的截图图标。框选区域、选择窗口或全屏，添加箭头、文字、马赛克等标注，然后点击“完成”复制图片并保存历史。

F2 看颜色，C 复制

普通截图时，鼠标旁显示 HEX / RGB 色值。按 F2 隐藏或显示取色框；取色框显示时按 C 复制 HEX 并结束截图。颜色示例：#6C57E5。

贴图，留下参考

点击“贴图”，将当前截图放到桌面，同时记录历史并保留原剪切板内容。拖动调整位置，滚轮缩放；右键可复制、关闭或设置边框。

取色快捷键用于普通截图的非文字输入状态，长图编辑中不使用这组操作。截图中的 Esc 会先取消当前绘制或选择，必要时再按一次退出。

页面太长，就用滚动长截图。

框选一个连续滚动区域，点击“长截图”。手动向下滚动，或在设置中选用自动滚动；自动滚动到底后会停在预览。

选择滚动区域→点击长截图→滚动与预览→完成，进入编辑→再次完成，复制入库

两个独立滚动的窗格请分别框选。遇到自动滚动无法响应的页面，可在预览中切换为手动滚动。

05 / NOTES & TODOS 1.1.7 新增

把想法和计划，放到桌面。

便签记下灵感与临时信息，待办承接接下来要做的事。两者独立保存，内容不进入剪切板历史。

单按 F3，记下一个想法。
快速双按 F3，添加一件待办。

也可使用快捷面板顶部的图标，或在管理页面新增。

① 先开启，再使用

进入“设置 → 便签与待办”，分别开启两个模块。相应的导航入口、快捷按钮和桌面列表才会出现。

② 选一块桌面区域

分别选择显示器和展示区域。每个列表只出现在一台显示器上，区域位置和大小从设置中修改。

③ 按自己的习惯管理

在管理页搜索、编辑或删除。关闭功能只隐藏入口和列表，已有内容和配置继续保留。

平时安静地留在桌面。
普通应用可以遮住列表；按 Win+D 显示桌面后仍可查看。快捷键添加时临时置顶，结束后回到底层。

快速新增窗口
Ctrl + Enter 保存
Esc 取消

文字和背景，都可以是你喜欢的样子。

便签和待办可分别设置默认字体、10–32 字号及文字颜色。新增或编辑单条内容时，可以覆盖这些默认值，也可以恢复“跟随列表”。F3 快速新增同样支持选色。

桌面卡片采用无边框毛玻璃，可调整背景色、渐变方式和透明度。100% 透明仍保留柔和毛玻璃；文字始终不透明。

离开 F3 或快捷面板打开的快速新增窗口，会保留本机草稿，下次快速添加时恢复。保存成功或按 Esc 取消后清除该草稿。毛玻璃基于静态桌面壁纸。

06 / PREVIEW

图片看完整，JSON 看层级。

选中记录后，右侧显示内容详情。需要时先看清楚，再决定如何使用。

图片按原比例展示

复制截图、浏览器图片或支持的图片文件后，历史中会生成预览。详情支持缩放，快捷面板也可悬停查看。

JSON 有两种复制方式

“复制内容”保留原始文本；“复制格式化 JSON”复制完整的格式化结果。可折叠节点，也可拖动分隔线调整阅读宽度。

07 / SYNC

需要时，再连接其他设备。

本地功能可以独立使用。希望多台电脑共享内容时，再配置你自己的 Git 仓库。

使用专用的私有仓库

  1. 准备一个 Gitee、GitHub 或 GitLab 私有仓库，以及具有所需读写权限的访问令牌。
  2. 在“云同步”选择平台，填写仓库 HTTPS 地址、用户名、令牌和分支，保存连接。
  3. 点击“立即同步”。另一台设备使用同一仓库和分支；按需选择 5、10 或 30 分钟的自动同步间隔。
电脑 A↔自己的 Git 私有仓库↔电脑 B
便签与待办，需要分别开启同步

同步内容、单条文字样式、完成和删除状态。模块关闭时暂停该模块同步；多设备同时修改的版本会保留，在管理页处理。

这些偏好留在当前电脑

显示器、展示位置、列表默认主题和未提交草稿保存在本机，不会被另一台电脑覆盖。

09 / QUESTIONS

几个常见问题。

关闭主窗口之后，应用还在运行吗？
会继续在系统托盘中运行并记录剪切板。左击托盘图标可打开全部历史；需要完全退出时，右击托盘图标，选择“退出应用程序”。快捷面板通过配置的快捷键打开。
为什么我看不到便签、待办入口？
两个模块默认关闭。进入“设置 → 便签与待办”，分别开启后，导航、快捷面板图标和桌面列表才会显示。只开启待办时，仍使用双按 F3 添加。
数据在哪里？换目录或升级会丢失吗？
默认数据位置是程序目录下的 data/idreaml_clip。应用会记住已配置的数据目录，升级时请保留它。需要迁移时，在“设置 → 快捷面板与历史 → 数据存储目录”选择新的空目录，由应用完成迁移和校验。自行备份时，请先退出应用，再保留整个数据目录。
清空剪切板历史，会把便签和待办一起删除吗？
不会。便签与待办使用独立模块保存，不进入剪切板历史，也不受历史清理规则影响。关闭便签或待办功能也会保留已有内容；永久删除需要在相应管理页操作。
为什么选择记录后没有自动粘贴？
目标输入框或应用权限可能限制自动粘贴。请先点击正确的输入位置，再呼出快捷面板；选择后内容仍保留在剪切板，可以手动按 Ctrl+V。桌面、任务栏或没有输入焦点的资源管理器场景通常仅执行复制。
我习惯用 Win+V，可以更换吗？
可以。在“设置 → 快捷键”开启“固定 Win+V 快捷键”，应用运行期间会用它呼出快捷面板，原自定义快捷键暂停。关闭该开关后恢复原组合；应用退出后释放拦截。
透明度调到 100%，为什么卡片还看得见？
这是预期效果。背景透明度控制毛玻璃上的底色，100% 透明仍保留静态壁纸的模糊效果和少量染色，文字保持不透明。它不会模糊动态视频壁纸、桌面图标或其他应用窗口。
Git 同步会覆盖多台电脑各自的桌面布局吗？
不会。便签与待办同步内容、单条文字样式以及完成和删除状态。列表位置、显示器、默认主题和草稿保留在各自电脑上。多设备并发修改会保留双方版本，由你在管理页选择。
这次也有 macOS 和 Linux 安装包吗？
1.1.7+1 本次仅发布 Windows x64 版本，便签与待办首期也在 Windows 上实现和验证。其他平台以后再适配；本页的操作步骤以当前 Windows 版为准。
