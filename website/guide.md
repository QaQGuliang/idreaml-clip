## 下载安装

本次发布为 Windows 1.1.8+1，统一应用 Logo、托盘与系统图标，以及网站和指南中的品牌素材。运行所需组件已随包提供，无需另外安装 Flutter、Dart 或 Git。

| 版本 | 安装方式 |

| [Windows 便携 ZIP][portable] · 约 18.8 MB | 完整解压到固定目录，再运行 `idreaml_clip.exe`。保留旁边的 DLL 和 `data` 目录。 |

从旧版升级时，请先从托盘退出旧版，并保留原数据目录。应用会继续使用已配置的数据位置。当前安装器尚未进行发布者代码签名。

## 三步上手

1. **启动应用。** 安装或解压后打开理梦剪藏。关闭主窗口后，应用仍在系统托盘中运行。
2. **复制一段内容。** 像平时一样复制文字、网址或图片。在“全部历史”里查看刚才的记录。
3. **用快捷键找回内容。** 先点击目标输入框，再按 `Ctrl + Shift + V`，选中一条记录即可使用。

试试复制这句话：把常用内容，留在顺手的位置。

## 快捷剪切板

快捷面板在鼠标附近打开，可以直接搜索和选取剪切板记录。

1. 点击需要输入内容的位置，按 `Ctrl + Shift + V` 打开面板。
2. 输入关键词筛选，或切到“收藏”。悬停图片和 JSON 可查看预览。
3. 单击记录，或用 `↑`、`↓` 选中后按 `Enter` 使用。按 `Esc` 收起面板。

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/quick-panel.png" alt="快捷剪切板：顶部便签、待办与截图入口，下方提供搜索、最近和收藏">

给常用回复、链接和代码片段加星收藏。复制相同内容时会合并记录，并保留使用次数和最近使用时间。若目标应用限制自动粘贴，可以按 `Ctrl + V` 手动粘贴。

## 截图与贴图

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/capture-toolbar.png" alt="截图工具栏：选择、标注、长截图、撤销重做、贴图和完成">

- **截图与标注。** 按 `F1` 或点击快捷面板顶部的截图图标。选择区域、窗口或全屏，添加箭头、文字、马赛克等标注，点击“完成”复制图片并保存历史。
- **取色。** 普通截图时，鼠标旁显示 HEX 和 RGB 色值。按 `F2` 隐藏或显示取色框，取色框显示时按 `C` 复制 HEX 并结束截图。文字输入和长图编辑期间停用取色快捷键。
- **贴图。** 点击“贴图”把当前截图放到桌面，同时记录历史并保留原剪切板内容。拖动调整位置，滚轮缩放。通过右键菜单复制、关闭或设置边框。

截图中的 `Esc` 会先取消当前绘制或选择，必要时再按一次退出。

### 滚动长截图

框选一个连续滚动区域，点击“长截图”。手动向下滚动，或在设置中选用自动滚动。自动滚动到底后会停在预览。点击“完成”进入编辑，编辑后再次点击“完成”复制入库。

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/long-editor.png" alt="长图编辑工具栏：标注、缩放、贴图、保存和完成">

长图编辑窗口支持跨屏拖动、缩放和多种箭头样式。两个独立滚动的窗格请分别框选。遇到无法响应自动滚动的页面，可在预览中切换为手动滚动。

## 便签与待办

便签和待办独立于剪切板历史保存。单按 `F3` 记下一个想法，快速双按 `F3` 添加一件待办。也可使用快捷面板顶部图标，或在管理页面新增。

| 便签 | 待办 |
| --- | --- |
| <img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/desk-notes.png" alt="便签管理界面"> | <img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/desk-todos.png" alt="待办管理界面"> |
| 支持标题与多行正文，集中搜索、查看和编辑。 | 勾选完成后从桌面收起，在管理页查看和恢复。 |

1. **开启模块。** 在“设置 → 便签与待办”分别开启功能。对应的导航入口、快捷按钮和桌面列表随后显示。
2. **选择区域。** 分别为两个列表选择显示器和展示区域。每个列表出现在一台显示器上，可在设置中修改位置、大小和外观。
3. **管理记录。** 在管理页搜索、编辑或删除。关闭功能会隐藏入口和列表，已有内容继续保留。

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/desk-settings.png" alt="便签与待办设置：模块开关、预览、显示器与展示区域">

普通应用可以遮住列表。按 `Win + D` 显示桌面后仍可查看。快捷键添加时窗口临时置顶，结束后回到底层。快速新增时按 `Ctrl + Enter` 保存，按 `Esc` 取消并清除本次草稿。直接离开快速新增窗口会保留本机草稿。

便签和待办可分别设置默认字体、10–32 字号及文字颜色。单条内容可自定义这些设置，或恢复“跟随列表”。快速新增同样支持选色。卡片支持调整毛玻璃底色、渐变和透明度，文字保持不透明。毛玻璃基于静态壁纸。

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/desk-settings-style.png" alt="文字样式与卡片外观设置：字体、字号、背景色和透明度">

## 图片与 JSON

选中记录后，右侧显示内容详情。

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/json-preview.png" alt="JSON 内容详情：左侧原文、右侧格式化与层级折叠">

- **图片。** 历史详情按原比例显示预览并支持缩放，快捷面板也可悬停查看。
- **JSON。** “复制内容”保留原始文本，“复制格式化 JSON”复制完整的格式化结果。可以折叠节点，或拖动分隔线调整阅读宽度。

## 云同步

本地功能可独立使用。如果需要在多台电脑间共享内容，可以连接自己的 Git 仓库。

1. 准备 Gitee、GitHub 或 GitLab 私有仓库，以及具有所需读写权限的访问令牌。
2. 在“云同步”选择平台，填写仓库 HTTPS 地址、用户名、令牌和分支，保存连接。
3. 点击“立即同步”。另一台设备使用同一仓库和分支。可选 5、10 或 30 分钟的自动同步间隔。

<img src="/idreaml/idreaml-clip/raw/branch/main/website/assets/cloud-sync.png" alt="云同步页面：平台选择和本地与云端状态">

便签与待办分别开启同步，覆盖内容、单条文字样式、完成和删除状态。模块关闭时暂停该模块同步。多设备同时修改会保留双方版本，可在管理页处理。显示器、展示位置、列表默认主题和草稿保存在各台电脑上。

## 快捷键

下表以 Windows 默认设置为准。快捷面板与截图的唤起键可在设置中修改。

| 按键 | 作用 | 使用位置 |
| --- | --- | --- |
| `Ctrl + Shift + V` | 打开快捷面板 | 先点击目标输入框，也可在设置中启用固定 `Win + V` |
| `↑` 或 `↓`，再按 `Enter` | 选择并使用记录 | 快捷面板打开时 |
| `Esc` | 收起面板 | 快捷面板打开时 |
| `F1` | 进入截图 | 应用正在运行时 |
| `F2` | 显示或隐藏取色框 | 普通截图中的非文字输入状态 |
| `C` | 复制 HEX 色值并结束 | 普通截图取色框显示时，非文字输入状态 |
| `1` / `2` | 减小或增大当前标注参数 | 随工具调整线宽、马赛克块或编号大小 |
| 按住 `Ctrl` | 临时选择和调整标注 | 松开后恢复原工具，文字输入期间保留文字操作 |
| 单按 `F3` | 新建便签 | 开启便签功能后 |
| 快速双按 `F3` | 新建待办 | 开启待办功能后，两次间隔约 330 毫秒以内 |
| `Ctrl + Enter` | 保存 | 快速新增窗口 |
| `Esc` | 取消并清除本次草稿 | 快速新增窗口 |

## 常见问题

### 关闭主窗口之后，应用还在运行吗？

会继续在系统托盘中运行并记录剪切板。左击托盘图标可打开全部历史；需要完全退出时，右击托盘图标，选择“退出应用程序”。快捷面板通过配置的快捷键打开。

### 为什么我看不到便签、待办入口？

两个模块默认关闭。进入“设置 → 便签与待办”，分别开启后，导航、快捷面板图标和桌面列表才会显示。只开启待办时，仍使用双按 F3 添加。

### 数据在哪里？换目录或升级会丢失吗？

默认数据位置是程序目录下的 `data/idreaml_clip`。应用会记住已配置的数据目录，升级时请保留它。需要迁移时，在“设置 → 快捷面板与历史 → 数据存储目录”选择新的空目录，由应用完成迁移和校验。自行备份时，请先退出应用，再保留整个数据目录。

### 清空剪切板历史，会把便签和待办一起删除吗？

不会。便签与待办使用独立模块保存，不进入剪切板历史，也不受历史清理规则影响。关闭便签或待办功能也会保留已有内容；永久删除需要在相应管理页操作。

### 为什么选择记录后没有自动粘贴？

目标输入框或应用权限可能限制自动粘贴。请先点击正确的输入位置，再呼出快捷面板；选择后内容仍保留在剪切板，可以手动按 Ctrl+V。桌面、任务栏或没有输入焦点的资源管理器场景通常仅执行复制。

### 我习惯用 Win+V，可以更换吗？

可以。在“设置 → 快捷键”开启“固定 Win+V 快捷键”，应用运行期间会用它呼出快捷面板，原自定义快捷键暂停。关闭该开关后恢复原组合；应用退出后释放拦截。

### 透明度调到 100%，为什么卡片还看得见？

这是预期效果。背景透明度控制毛玻璃上的底色，100% 透明仍保留静态壁纸的模糊效果和少量染色，文字保持不透明。它不会模糊动态视频壁纸、桌面图标或其他应用窗口。

### Git 同步会覆盖多台电脑各自的桌面布局吗？

不会。便签与待办同步内容、单条文字样式以及完成和删除状态。列表位置、显示器、默认主题和草稿保留在各自电脑上。多设备并发修改会保留双方版本，由你在管理页选择。

### 这次也有 macOS 和 Linux 安装包吗？

1.1.8+1 本次仅发布 Windows x64 版本，便签与待办首期也在 Windows 上实现和验证。其他平台以后再适配；本页的操作步骤以当前 Windows 版为准。
