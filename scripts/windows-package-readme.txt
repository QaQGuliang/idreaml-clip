Idreaml Clip（理梦剪藏）— Windows x86-64

使用方法
1. 将整个 ZIP 解压到一个固定目录。
2. 双击 idreaml_clip.exe 启动；请保留旁边的 DLL 和 data 目录。
3. 默认 Ctrl + Shift + V 呼出快捷剪切板，可在设置中更换完整组合。
4. 关闭主窗口后仍在托盘运行；完全退出请使用托盘右键菜单的“退出应用程序”。
5. 同一 Windows 登录会话只运行一个实例，重复启动会打开已有程序的全部历史。

截图功能
1. 默认按 F1 截图，可在“设置 → 快捷键 → 截图快捷键”中修改；也可点击快捷剪切板顶部的截图图标。
2. 截图按钮会先收起快捷剪切板。可在任意扩展显示器上框选、将选区拖到另一块屏幕，或一次框选跨屏内容。
3. 框选区域或选择窗口、全屏后，可使用图形、箭头、画笔、文字、马赛克、实心遮盖和自动编号等工具标注。
   普通截图和长截图都可在箭头工具旁选择单向、实心、空心、双向、虚线或折线箭头。实心和空心样式使用尖尾轮廓。需要固定常用样式时，在“设置 → 截图与贴图 → 默认箭头样式”中选择。
   绘制图形、箭头、画笔或荧光笔时，按 1 变细、2 加粗；马赛克调整块大小，自动编号调整数字与圆标大小。支持小键盘和长按连续调整。文字与自动编号显示字号，输入文字时数字键照常输入。
   按住 Ctrl 临时切到「选择 / 调整」，松开后恢复原标注工具。正在拖动时会先完成当前操作再切换；文字输入期间保留 Ctrl 组合键。
4. 完成后复制最终图片并保存历史，不会自动打开历史列表或粘贴到其他应用。应用运行期间持续记录剪切板。
5. 点击“另存为”可保存 PNG 副本，并同步完成复制、入库及退出；保存目录会自动记住。
6. 进入截图默认使用「选择 / 调整」工具，可先调整选区。工具栏优先排成一行（最多两行），当前工具的颜色、粗细和字号等样式直接显示在工具右侧，选择工具下隐藏；一行放不下时收起为展开/隐藏按钮。默认位于选区左下角（无选区时为屏幕左下角），可能与选区内容重叠，按住工具栏空白区域可拖动，本次截图内保持该位置。
7. 点击带图钉图标的「贴图」按钮，可将截图置顶并保存到历史。拖动贴图调整位置，滚动鼠标滚轮缩放。
8. 右键贴图，打开「当前贴图边框」可为这一张选择无边框、浅色、深色或琥珀色。复制和历史记录保留原图。
9. 在贴图右键菜单的「全局默认边框」或「设置 → 截图与贴图 → 贴图默认边框」中选择默认样式。新贴图默认跟随全局，已单独设置的贴图可选「跟随全局设置」恢复联动。
10. 框选一个连续滚动区域后点击「长截图」。默认手动滚动，也可在「设置 → 截图与贴图 → 长截图滚动方式」中选择自动滚动。同一页面可跨屏，选区应避开屏幕间的空白和独立滚动的窗格。
11. 自动滚动到底后会停在预览。点击「完成」进入可跨屏拖动的长图编辑窗口，再次点击「完成」复制并保存到历史。

桌面便签与待办
1. 在“设置 → 便签与待办”分别开启，管理入口及快捷剪切板顶部的图标按钮随开关显示。
2. 单按 F3 添加便签，快速双按 F3 添加待办；Ctrl+Enter 保存；Esc 或直接离开窗口会保留草稿，点击“取消”才清除。保存时字段错误会标红并在附近提示，便签标题最多 120 字。
3. 新建或编辑待办时，可设置可选的开始、结束时间（日期和时分），结束不能早于开始。提醒可选开始前 5/15/30/60 分钟或自定义分钟（需先设开始时间），也可指定日期时间，或不提醒。
4. 应用运行期间到点会弹 Windows 系统通知，点击通知进入待办页；应用未运行而错过的提醒会在下次启动时汇总提示一次。待办完成后不再提醒，修改时间或提醒会重新排定，同一提醒不会重复弹出；关闭待办模块时不安排提醒。
5. 列表默认位于其他应用下方，Win+D 后仍可查看；快捷键新增时临时置顶，结束后恢复底层。
6. 在设置中指定各自的显示器和展示区域，调整背景色、渐变与透明度。100% 透明仍保留壁纸毛玻璃，文字不随背景变透明。
7. 管理页显示“今天/明天”、跨天或截止时间，桌面待办卡片显示日期与时分。未完成且已过期的待办在管理页标红并显示“已逾期”，桌面卡片时间标红；有开始时间的未完成待办按开始时间排在前面。
8. 可分别设置默认字体、10–32 字号和字色；管理页新增/编辑可为单条设置覆盖样式或恢复跟随列表。选色使用同一套 18 色色板，也可输入 6 位 HEX 值。
9. 管理页支持搜索、编辑、删除及恢复已完成待办；桌面待办可以直接勾选完成。
10. 内容保存在独立数据库，不计入剪切板历史。分别开启同步后，内容、时间/提醒、单条样式和完成/删除状态同步；显示配置、已提醒状态及草稿仅在本机保存。

支持 Windows 10 / Windows 11 的 x86-64 系统。
已附带所需的 Visual C++ x64 运行库，无需安装 Flutter 或 Dart。
ZIP 为免安装分发包；历史、图片、设置等默认统一保存在安装目录的 data/idreaml_clip 中。
可在“设置 → 快捷面板与历史 → 数据存储目录”手动输入路径或点击“选择文件夹”选择新的空目录；确认后迁移并校验全部数据，再删除旧目录。
更新前请退出旧版本并保留原数据目录。新版仍会读取已配置的位置，需更换位置时使用设置中的迁移功能。
“设置 → 启动与权限 → 以管理员身份启动”默认关闭；开启后请求 Windows 授权并重启，以后保留该偏好。
取消授权会保留原程序和设置；关闭开关从下次普通启动生效。数据迁移已支持只读 Git 文件，无需因此开启管理员模式。
开机自启：在“设置 → 启动与权限”中开启“开机自动启动”，应用会在当前账户的 Windows
启动文件夹创建 Idreaml Clip.lnk，并在保存后延迟校验。无需手动修改注册表。
升级时会迁移此前已开启自启的选择，并清理旧的 Run 项以避免重复启动。
回到主窗口或进入设置时会刷新实际状态，启动项丢失时会提示重新开启。
移动程序后请先打开新目录中的应用；若旧目录仍保留，请在新版设置中开启自启，
将启动项指向新版。Windows 中主动禁用的启动项不会被自动重新开启。
