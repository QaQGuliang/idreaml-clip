# 理梦剪藏使用指南

[返回项目首页](../README.md) · [打开完整图文网站](https://qaqguliang.github.io/idreaml-clip/)

本文保留详细功能说明和操作边界，当前使用步骤以 Windows 1.1.9+9 为准。

Idreaml Clip 是一款面向桌面端的本地优先剪切板管理工具。它会自动保存你复制过的文本，Windows 版也支持截图和图片，让临时复制的内容不再因为下一次复制而丢失。

无论是整理资料、编写文档、处理代码，还是在多个应用之间频繁搬运内容，Idreaml Clip 都能帮助你快速找回、搜索并再次使用历史剪切板内容。

当前版本为 **1.1.9+9**。本版为待办增加可选的时间与提醒，同步记录改为折叠摘要并可打开明细页；截图编辑器默认使用“选择 / 调整”工具，工具栏收拢为单行优先并避免遮挡选区；便签、待办与设置统一使用 18 色色板和 HEX 自定义颜色。完整改动见[本版更新说明](../assets/release-info.json)。

在 [GitHub Releases](https://github.com/QaQGuliang/idreaml-clip/releases/latest) 下载 Windows x64 安装包或便携 ZIP；每个版本同时提供 SHA-256 校验文件。本次仅发布 Windows 版本。

Windows 版支持 Windows 10/11 x64；Mac 测试包目标为 Apple Silicon（M 系列）与 macOS 13+，使用免费 ad-hoc 本地签名，不包含苹果公证。当前 Mac 功能范围是本地文本记录、搜索、收藏、JSON 预览和快捷面板；图片采集与写回、自动粘贴、同步令牌存储尚未适配。

完整的应用介绍、安装步骤和界面截图见[图文网站](https://qaqguliang.github.io/idreaml-clip/)。网站源码位于 [website/](../website/)。本地讨论、开发设计与打包记录保存在不纳入版本控制的 `doc/` 中。打包入口见 [Windows 打包脚本](../scripts/package-windows.ps1)、[Windows 安装器脚本](../scripts/package-windows-installer.ps1)和 [macOS 打包脚本](../scripts/package-macos.sh)。

在项目根目录运行 `python scripts/build-user-guide.py`，可从网站源码和图片生成离线单文件指南。生成前会核对网站与版本信息；图像和网站图标会嵌入 HTML，无需联网即可阅读。输出位于 `doc/使用指南/`，并同步无版本的 `配套资料/使用指南.html`；历史版本指南保持不变。

## 产品介绍

### 自动记录，随时找回

Idreaml Clip 在后台监测系统剪切板变化，不依赖 Ctrl+C 或 Ctrl+V 按键。Windows 版可记录纯文本、截图、浏览器“复制图片”和复制的 PNG/JPG/GIF/BMP/WebP 图片文件。复制过的信息会按照最近使用时间排列，无需提前分类或手动保存。

图片在历史列表使用较大的矩形预览，按原比例完整显示；快捷面板显示缩略图，详情支持缩放查看，复制时写回系统图片格式。详情右上角随所选内容显示 TEXT、JSON、PNG、JPG 等类型；JSON 对象或数组需要解析有效，原始文本保持不变。系统位图截图转换为 PNG，有原始图片编码时保留其格式。单张编码图片上限 32 MB，解码上限 4000 万像素，超限时显示提示。

相同内容会自动合并，并记录使用次数，避免历史列表出现大量重复条目。

### 快捷面板，提高复制效率

通过全局快捷键可以随时呼出快捷面板。Windows 默认 `Ctrl + Shift + V`，macOS 默认 `Control + Option + V`，Linux 默认 `Ctrl + Alt + V`。在“设置 → 快捷键 → 全局快捷键”中点击录入区域，直接按下想使用的完整组合（例如 `Alt + Q`、`Ctrl + Alt + J` 或单个 `F8`），松开全部按键后保存。修饰键和主键均可更换，支持平台可注册的字母、数字、标点、方向键及功能键。保存后立即生效，重启后保留，也可以恢复默认。录入期间旧快捷键暂停生效，取消编辑后恢复；`Esc` 可取消本次录入。Windows 会检查组合是否被占用或保留。面板采用约 347 × 427 的紧凑尺寸，在鼠标附近显示，并自动避开屏幕边缘和任务栏。

Windows 版另提供“设置 → 快捷键 → 固定 Win + V 快捷键”开关，默认关闭。开启后，在应用运行期间拦截 `Win + V` 并呼出本应用的快捷面板，自定义快捷键置灰且停止生效，原组合仍独立保留。关闭开关后恢复原自定义组合；开关状态在重启后保留。该选项不出现在 macOS/Linux 中。拦截随应用退出释放，不修改 Windows 的剪切板历史设置。锁屏、UAC 安全桌面不属于此功能范围。

单击条目即可复制并收起面板。Windows 会恢复快捷键唤起前的应用窗口与键盘焦点。标准 Edit、RichEdit 输入框通过原生粘贴命令插入文本，其他编辑器和图片粘贴由目标应用处理一次 `Ctrl+V`。使用前请先点击目标输入框。桌面、任务栏及未聚焦输入框的资源管理器仅复制。目标失效、切换应用或目标软件拒绝输入时，内容仍保留在系统剪切板。右击条目可选择“复制”（仅复制）或“删除”。点击面板外部或按 `Esc` 可关闭面板。

快捷面板采用无边框窗口，内容紧贴窗口边缘。鼠标悬停在图片或有效 JSON 条目上时，会在旁边弹出预览，并根据屏幕剩余空间选择左右位置。图片按原始横竖比例直接展示，没有卡片底色、边框或投影，可缩放查看；JSON 仍以卡片显示，自动缩进格式化并支持滚动。复制和粘贴仍使用原始内容。移出条目及预览区域后，预览自动收起。

快捷面板支持键盘操作：

- 使用 `↑`、`↓` 选择内容；
- 按 `Enter` 使用选中内容，与单击条目相同；
- 按 `Esc` 关闭快捷面板；
- 输入关键词快速查找历史内容。

### 截图与滚动长截图（Windows）

按 `F1` 或点击快捷面板顶部的截图图标进入截图，快捷键可在设置中修改。使用多个扩展显示器时，可以在任意屏幕开始框选，把选区拖到另一块屏幕，也可以一次框住横跨多屏的内容。导出的 PNG 保留原始像素，屏幕排列中没有显示区域的部分为透明。普通截图也支持选取窗口、截取单个全屏和标注。点击「完成」会复制图片并记录历史，点击「另存为」还会保存 PNG 副本。

多屏桌面的外接矩形最长边支持 16384 像素，总面积最多 4000 万像素。单张输出 PNG 最大为 32 MB。

进入截图或长图编辑时默认使用「选择 / 调整」工具，可先调整选区，或移动、缩放已有标注，再切换到标注工具。普通截图的工具栏优先排成一行，空间不足时最多两行；颜色、粗细和字号收进工具栏的「标注样式」弹层。工具栏默认放在选区下方的空白处，依次尝试下方、上方、右侧和左侧；接近全屏、四周没有空白时贴最近的屏幕边缘显示。按住工具栏空白背景可以拖动它，全屏和非全屏均可，尽量避免遮挡框选内容。

普通截图和长图编辑都支持单向、实心、空心、双向、虚线和折线箭头。单向箭头使用细杆与实心三角头，实心和空心箭头使用由尖尾逐渐加宽的轮廓。选择「箭头」后打开「箭头样式」查看预览，拖动即可绘制。要修改已画好的箭头，用「选择 / 调整」点中它，再切换样式。「设置 → 截图与贴图 → 默认箭头样式」可以指定每次截图的起始样式，也可以沿用上次选择。

矩形、椭圆、直线、箭头、画笔和荧光笔支持按 `1` 变细、`2` 加粗，包括按住鼠标绘制期间。主键盘和小键盘均可使用，长按可连续调整，选中已有标注也可修改。马赛克使用相同按键调整块大小，自动编号使用相同按键缩小或放大数字与圆标。字号仅在文字和自动编号工具中显示，输入文字时数字键照常输入。

使用标注工具时，按住 `Ctrl` 可临时切到「选择 / 调整」，选中、移动或缩放已有标注；松开后恢复原工具。若正在拖动鼠标，会先完成当前操作再切换。文字输入期间保留原有的 `Ctrl` 组合键。

选好区域或全屏后，点击工具栏的「贴图」按钮，可将包含标注的截图贴在原位置，并计入历史。贴图时保留剪切板内容。可以同时打开多张贴图，拖动调整位置，滚轮缩放，右键复制或关闭。

右键桌面上的贴图可以为当前这张选择无边框、浅色、深色或琥珀色边框。新贴图默认跟随全局设置，初始为无边框。在应用设置或贴图右键菜单中修改全局默认边框，所有跟随全局的贴图会立即更新。单独设过边框的贴图可选「跟随全局设置」恢复联动。边框仅在桌面显示，复制和历史记录保留原图。

进入普通截图时，鼠标旁的取色框显示原始像素的 HEX 和 RGB 色值。按 `F2` 临时隐藏或显示，取色框显示时按 `C` 可复制 HEX 并退出截图。每次截图的初始显示状态可在设置中修改。取色快捷键仅用于普通截图的非文字输入状态，长图编辑中不使用这组操作。普通截图中按 `Esc` 会先取消当前绘制或选中标注，必要时再次按下即可退出。

截长图时，框选页面或整个窗口，再点击工具栏的「长截图」。选区可以包含滚动条、固定工具栏和播放中的视频。软件根据随页面一起移动的文字、图片等内容拼接。若两个窗格各自滚动，请分别框选。同一页面可以横跨多块显示器，选区需要全部落在可见屏幕内。

- 默认手动滚动。遇到跳页或前后画面接不上时，预览会提示最后接上的画面，稍微往回滚到能衔接的位置即可继续，也可以直接完成。
- 在设置中选择「自动滚动」后，下次长截图会从页面当前位置开始。到达底部或达到长图上限（最长 8192 像素，总像素最多 1600 万）时会停在预览。采集中也可以切换为手动滚动。
- 看过预览后点击「完成」，长图会在可调整大小的窗口中打开。顶部同一行可以标注、调整缩放或适应宽度，窗口较窄时从「更多」打开其余工具。拖动标题可将窗口移到另一块屏幕，再点「完成」复制并保存历史。采集时按 `Esc` 可取消。

### 桌面便签与待办（Windows）

在“设置 → 便签与待办”分别开启两个模块。开启后，左侧管理入口和快捷面板标题栏的图标按钮才会显示；图标悬停显示名称。单按 `F3` 新建便签，330 毫秒内双按 `F3` 新建待办。只开启待办时仍须双按 F3；只开启便签时单按即可添加。截图中的 `F2` 继续用于取色器显示与隐藏。

便签和待办以固定区域的纵向卡片列表显示在桌面，其他应用可以遮住列表，`Win + D` 显示桌面后仍可查看。快捷键添加时，对应列表临时置顶。F3 或快捷面板打开的快速新增窗口支持 `Ctrl + Enter` 保存；按 `Esc` 或直接离开窗口会保留本机草稿，下次快速添加时恢复，保存或点击「取消」后清除草稿。结束快速添加后列表恢复底层。管理页新建和编辑通过按钮保存或取消。正文支持多行，便签另有可选标题。

新建或编辑待办时，可设置可选的开始时间和结束时间（日期与时分），结束时间不能早于开始时间。提醒可选择在开始前 5、15、30、60 分钟或自定义分钟（需先设置开始时间），也可以指定日期时间；没有开始时间时只能按指定时间提醒，也可以不设置提醒。应用运行期间到点会弹出 Windows 系统通知，点击通知进入待办管理页；应用未运行而错过的提醒，下次启动时汇总提示一次。待办完成后不再提醒；修改时间或提醒会重新排定，同一条提醒不会重复弹出。关闭待办模块时不会安排提醒。

快速新增和管理页保存时会逐项校验。内容为空、便签标题超过 120 字或时间与提醒设置有误时，出错字段边框标红并在旁边说明原因，焦点移到第一个错误字段。

在设置中选择展示显示器、框选区域、调整背景色、渐变方向和背景透明度。每个列表只显示在一台显示器上；区域位置和大小只能从设置修改。显示器断开后临时回退主屏，重新连接后恢复原配置。便签默认位于左侧，待办默认位于右上角并使用任务栏之外的可用高度，默认宽度为 320 个逻辑像素。

桌面条目没有外框，100% 透明仍保留基于桌面壁纸的毛玻璃效果，文字始终清晰、不透明。便签和待办可分别设置默认字体、10–32 字号及文字颜色；单条新增或编辑时可覆盖这些样式，也可恢复“跟随列表”。F3 快速新增支持选色，管理编辑提供文字预览。设置和管理页选色使用同一套 18 色色板，自定义颜色输入 6 位 HEX 值；快速新增在窗口内展开同一色板。毛玻璃基于静态桌面壁纸，不包含动态壁纸、桌面图标或置顶时后面的应用画面。

桌面卡片支持滚动和打开全文，待办可直接勾选完成；编辑、搜索、删除和恢复已完成待办在管理页进行。已完成待办从桌面隐藏，管理页持续保留。关闭功能会隐藏入口和列表，并保留已有内容、设置与草稿。

管理页会显示安排的时间：当天区间显示为“今天 09:00–10:00”，跨天显示起止日期与时分，只有结束时间时显示“截止 …”。桌面待办卡片会显示对应的日期与时分。未完成且已到结束时间（没有结束时间时按开始时间）的待办在管理页标红并注明“已逾期”，桌面卡片的时间也会标红。有开始时间的未完成待办在管理页和桌面都按开始时间排在前面。

两个模块保存在独立的 `database/desktop.db`，新增、编辑以及从便签/待办编辑框复制的内容不会计入剪切板历史。清空剪切板历史不影响这些内容。分别开启模块同步后，便签和待办在仓库的 `notes/` 和 `todos/` 下各自保存，每条一个 Markdown 文件。同步内容、时间与提醒、单条文字样式、完成和删除状态。显示器、默认主题、开关、草稿和已提醒状态保存在本机。关闭模块时暂停该模块同步。多设备并发修改会保留双方版本，在管理页选择保留版本。删除会同步到其他设备，旧 Git 提交保留。

### 搜索、收藏与历史管理

全部历史支持关键词搜索和今日内容筛选。经常使用或不希望被自动清理的内容，可以加入收藏。

选中 JSON 记录时，内容详情左右分栏：左侧保留原始文本，右侧以语法配色、行号和层级引导线展示 JSON。点击对象或数组前的箭头可单独折叠和展开，也可使用“展开全部”“折叠全部”。两侧独立滚动，深层内容支持横向滚动。右侧“复制格式化 JSON”始终复制完整解析结果，底部“复制内容”仍复制原文。

JSON 识别支持标准转义引号、整体转义但省略外层引号的文本，以及多次编码的 JSON 字符串。解析仅还原整段文本的外层编码，保留字段内字符串、反斜杠路径和转义字符的含义；原始剪切板记录保持不变。快捷面板的 JSON 预览使用同一识别规则。

拖动历史列表与内容详情之间的分隔线，可调整列表和预览宽度。左侧导航栏边界也可以拖动，缩窄后保留图标入口，悬停可查看名称；向右拖动恢复文字。布局会保存在本机，切换页面或重启后保留。

“设置 → 快捷面板与历史 → 历史保存数量”提供 1,000、5,000、10,000、50,000 条预设，也可选择“自定义”输入任意正整数。保存后立即生效并在重启后保留，超出的最旧非收藏记录会被自动清理。

在全部历史中可以收藏、取消收藏或删除历史记录。删除历史只影响全部历史列表。隐私页面的「清空历史」会移除全部历史中的所有条目，已收藏的内容仍可在收藏里查看和复制。收藏页提供取消收藏；如果该条目的历史也已删除，取消后两个列表均不显示该内容。

### 本地优先，数据由你掌控

Idreaml Clip 不要求注册账号，也不依赖云端服务。即使没有网络或未配置同步，剪切板记录、搜索、收藏和快捷面板仍然可以完整使用。

应用运行期间持续记录剪切板内容，数据首先保存在本机数据库中。是否启用云同步由你自行决定。

### 使用自己的仓库同步

需要在多台设备间共享剪切板时，可以连接 Gitee、GitHub、GitLab 或自托管的 Git 私有仓库。

Idreaml Clip 内置 Git 能力。仓库的当前提交可直接查看或下载内容：

| 目录 | 内容 |
| --- | --- |
| `history/年-月-日/` | 按北京时间的首次记录日期归档，每条一个原文或原图文件 |
| `favorites/` | 每条收藏一个可直接打开的原文或原图文件 |
| `notes/`、`todos/` | 每条便签或待办一个 Markdown 文件，有并发冲突时保留各版本 |
| `config/` | 格式版本、设备信息、记录状态、样式和删除标记 |

应用按所选分支的最新提交同步。删除历史或取消收藏会移除当前提交里的对应文件，之前的 Git 提交仍可用于恢复。仓库文件用于查看、下载和恢复，应用内编辑请从应用操作。

其他同步功能包括：

- 手动立即同步；
- 应用启动后自动同步；
- 每 5、10 或 30 分钟定时同步；
- 多设备内容去重；
- 收藏、删除和最近使用状态合并；
- 查看参与同步的设备和最后活跃时间。

访问令牌只保存在本机的系统安全凭证中，不会写入剪切板数据库或同步仓库。同步异常也不会影响本地剪切板的正常使用。

### 安静地运行在桌面后台

关闭主窗口后，Idreaml Clip 会继续在系统托盘中运行并监听剪切板。左键单击托盘图标进入“全部历史”；右键菜单提供“退出应用程序”。快捷面板通过配置的快捷键唤起。点击桌面或菜单外部即可关闭菜单，无需选择选项。悬停标题为 `Idreaml Clip`。你也可以根据需要开启开机自动启动。

## 使用介绍

### 1. 开始记录

启动 Idreaml Clip 后，应用会自动监听新的剪切板内容。像平时一样在任意应用中复制文本、复制图片或截图到剪切板即可，无需额外操作（图片采集目前支持 Windows）。

应用启动后自动开始记录，关闭主窗口后仍在托盘中持续记录；从托盘菜单退出程序后结束记录。隐私页面可以管理历史保留时间和清空历史。

### 2. 查看和搜索历史

打开“全部历史”页面即可查看保存过的剪切板内容。

- 在顶部搜索框输入关键词查找内容；
- 使用“今天”筛选当天复制的记录；
- 点击一条记录查看完整内容和使用信息；
- 点击复制按钮，将内容重新放入剪切板。

### 3. 收藏常用内容

在历史列表或内容详情中点击星标，即可将内容加入“我的收藏”。

收藏适合保存邮箱、常用回复、代码片段、地址等需要反复使用的信息。再次点击星标即可取消收藏。

### 4. 使用快捷面板

在任意应用中按下配置的快捷键（Windows 默认 `Ctrl + Shift + V`）呼出面板。也可在设置中启用固定 `Win + V`。管理页面和托盘右键菜单不提供快捷面板入口。

你可以单击记录，也可以使用方向键选择记录并按 `Enter`；Windows 下会返回原应用的键盘焦点并尝试自动粘贴。请先点击目标输入框；若无法自动粘贴，可手动按 `Ctrl+V`。悬停图片和 JSON 记录可查看预览。右击记录可以仅复制或删除；点击窗口外部或按 `Esc` 收起面板。输入关键词可搜索全部历史，面板也支持只显示收藏内容。

### 5. 配置云同步

启用云同步前，建议创建一个专门用于 Idreaml Clip 的私有空仓库，并准备具有该仓库读写权限的账号。自托管服务器需提供可拉取、可推送的 Git HTTP 或 HTTPS 克隆地址。

配置步骤：

1. 打开“云同步”页面；
2. 选择 Gitee、GitHub、GitLab 或「自托管 Git」；
3. 填写仓库的克隆地址。自托管 Git 支持 HTTP 和 HTTPS，也可指定端口，如 `http://192.168.1.10:3000/team/clip.git` 或 `https://git.example.com:8443/team/clip.git`；
4. 填写 Git 用户名和访问令牌。自托管服务器也可填写服务器允许用于 Git 验证的密码；
5. 确认同步分支，默认为 `main`；
6. 保存连接后点击“立即同步”；
7. 根据需要选择 5、10 或 30 分钟的自动同步间隔。

页面下方的“同步记录”默认折叠，只显示记录数量、最近同步时间和最近一次成功或失败（记录涵盖手动、启动和定时同步）；最近一次失败时会显示红点。点击“查看全部”进入独立页面，记录按天分组，并可按全部、成功或失败筛选。失败记录会标明失败阶段。记录保存在本机，满 7 天后自动删除。

用户名和凭据请填写在各自的输入框。切换仓库地址或账号时，需要填写新连接的凭据。

自托管 Git 默认校验 HTTPS 证书。如果服务器使用自签名证书，或证书与域名不一致，可以在确认信任服务器后开启「跳过 HTTPS 证书校验」。开启后应用无法验证服务器身份。该选项只对当前自托管连接生效，修改克隆地址后需要重新选择。

HTTP 会明文传输凭据和同步数据，请在可信网络中使用。

首次连接自托管 Git 时，应用只下载当前分支的最新快照。快照仍包含各设备已同步的内容和删除记录。如果拉取时遇到 HTTP 5xx 或数据包传输中断，可按同步记录中的时间检查 Git 服务及反向代理的日志。

从旧版迁移时，在新版本打开「云同步 → 导入旧仓库」，可从当前连接只读导入，或选择旧仓库已下载的工作目录。导入会合并本机尚未上传的内容。确认历史、收藏、图片、便签和待办后，连接新的私有仓库，再点击「立即同步」。需要上传便签和待办时，请打开对应模块的同步开关。其余设备升级后连接同一个新仓库和分支。

升级时，旧版曾因历史删除而隐藏的收藏，只要本机数据库仍保有收藏标记和原内容，就会重新显示在收藏页。若旧仓库的最新提交只剩删除记录，需从仍保有原内容的设备或旧 Git 提交找回。旧版记录没有独立的收藏操作时间，迁移时会保留能读到的收藏，之后以新版的收藏和取消收藏操作为准。

### 6. 管理同步设备

在「设备」页面可查看设备名称、设备编号、操作系统和最后同步时间。Windows 版根据固件提供的 UUID 生成应用专用编号，列表按完整编号去重，名称下显示短编号。同名且编号不同的设备分别显示；设备改名时显示最新上报的名称。缺少编号的旧记录按原有应用 ID 识别，并标注「旧记录 · 无设备编号」。

新设备只需安装 Idreaml Clip，并连接同一个仓库和分支，即可导入已有记录。

### 7. 调整存储与桌面设置

设置首页按用途列出分类。点击分类后在当前窗口查看详情，点击返回即可切换分类。

- 在**快捷键**中调整快捷面板和截图的快捷键。Windows 也可在此设置固定 Win + V。
- 在**快捷面板与历史**中调整面板显示数量和历史保存上限，查看或迁移本地数据目录。
- Windows 用户可以在**截图与贴图**中设置取色器、长截图滚动方式、默认箭头样式和贴图边框。
- 在**便签与待办**中分别开启模块，设置桌面区域、文字样式、卡片外观与模块同步。
- 在**启动与权限**中调整开机自动启动。Windows 也可在此设置以管理员身份启动。

收藏内容不会被常规的自动清理规则移除。

Windows 的“设置 → 启动与权限 → 以管理员身份启动”默认关闭。开启后先保存偏好，再通过系统 UAC 请求授权；确认后正常关闭原进程并以管理员身份重启，以后启动时沿用该偏好。当前已为管理员时直接保存，不重复重启。取消授权或新进程创建失败时保留原进程与原设置。关闭开关后，下次从桌面普通启动时生效；界面显示当前实际运行身份。该功能不改变系统 UAC 策略，每次提权仍按 Windows 设置请求确认。

数据目录迁移支持 Windows 只读 Git 对象，不依赖管理员权限。仅在新副本校验完成并提交新位置后，才清理旧副本的只读属性以删除旧目录。迁移中的文件访问错误会显示具体文件及系统错误信息，便于区分权限不足、文件占用和空间不足。

默认数据目录为安装目录下的 `data/idreaml_clip`（macOS 位于 `.app` 所在目录下，避免修改应用签名）。内容按用途分开保存：

| 路径 | 内容 |
| --- | --- |
| `database/clipboard.db` | 文字记录、收藏、图片索引、设备信息和截图回执 |
| `database/desktop.db` | Windows 便签、待办、同步版本及本机展示设置和草稿 |
| `images/` | 图片和截图原始文件，以内容哈希命名 |
| `config/settings.db` | 软件设置、快捷键、窗口布局、同步配置和最近 7 天的同步记录 |
| `credentials/` | Windows DPAPI 加密的同步密码或访问令牌 |
| `sync/` | Git 同步仓库缓存 |

在“设置 → 快捷面板与历史 → 数据存储目录 → 更改目录”手动输入完整路径，或点击“选择文件夹”通过系统窗口选择空目录；也可手动输入尚未创建的目录。选择后只回填路径，仍需点击“保存”并确认迁移。设置卡片下方会说明各子目录和文件的用途。路径相同时不执行迁移；路径不同时，确认框会列出新旧位置，并说明旧目录及其内容将被删除。确认后等待当前写入和同步完成，复制并逐文件校验，验证新数据库、保存新位置后才清理旧目录。目标目录非空或新旧目录互相包含时会拒绝迁移。提交新位置前发生错误会恢复原目录；提交后清理被占用的旧文件失败时会提示，并在下次启动重试清理。

旧版本的数据会在首次启动时转换并迁移到默认位置；默认位置不可写时保留原数据，并在设置页提示更换目录。新安装遇到权限问题时可以在启动提示页指定可写的空目录。已配置目录暂时离线时不会创建空历史覆盖原配置。

系统应用支持目录只保留 `storage-location.json`，用于启动时找到用户选择的目录及恢复未完成的清理，不包含剪切板内容或软件偏好。备份时应复制整个数据目录；加密令牌仍只能由原 Windows 账户解密。用户主动“另存为”的截图副本不受数据目录迁移影响。

### 8. 退出应用

点击窗口关闭按钮时，应用默认隐藏到系统托盘并继续工作。

如需完全退出，请右击系统托盘中的 Idreaml Clip 图标，并选择“退出应用程序”。

## 使用建议

- 为云同步使用独立的私有仓库，不要与其他项目文件混用；
- 为访问令牌仅授予同步仓库所需的最小权限；
- 不希望继续记录时，从系统托盘退出程序；
- 第一次在新设备上连接仓库后，先执行一次“立即同步”；
- 分发或移动 Windows 版本时，请保留 Release 目录中的全部文件，不要只复制可执行文件。
